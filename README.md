# Floquet-BEC-SSFM-Solver
This repository contains the code for solving the time-dependant Gross-Pitaevskii equation using a custom SSFM solver.
- All the required libraries are there in the first cell, which must be run before running any other cell.
- The code follows a sequential order (apart from the "main" cell), the parameters can be changed as per the user requirement.
- The ground state is estimated via imaginary time propagation (Wick rotation) until the chemical potential saturates to some value, under a tolerance of 1e-10.
- The "main" cell must be run after all the other cells are run.
